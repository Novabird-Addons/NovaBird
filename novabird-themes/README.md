# NovaBird-Themes

Drei Themes für **Betterbird** / Thunderbird ESR, jeweils hell und dunkel in einem Paket (folgt dem Modus des Betriebssystems). Deutsch, English, Français, Español.

| Theme | Charakter | Version |
|---|---|---|
| **NovaBird-Sand** | ruhig, warme Grautöne, Blau nur als Akzent | 1.0.0 |
| **NovaBird-Cobalt** | kompakt, kräftiges Blau, starke Kontraste | 1.0.2 |
| **NovaBird-Springlight** | neutral hell mit frischem Blau, graphit im Dunkel | 1.7.2 |

Kontraste sind geprüft (Text ≥ 4,5 : 1, Symbole ≥ 3 : 1). Die Themes stylen die Hauptansichten (Mail inkl. Kartenansicht, Kalender, Adressbuch, Einstellungen).

## Mit der NovaBird-Extension
Ein Theme kann keine Dialogfenster, Einstellungsseiten oder Skripte gestalten. Die [NovaBird-Extension](../novabird-extension/) übernimmt die Farben des aktiven Themes für Termin-Dialoge, Einstellungen, Verfassen und die rechte Leiste. Beides funktioniert auch einzeln (ohne Extension bleiben diese Teile im Standardstil).

## Installation
`novabird-t-<name>-<Version>.xpi` im Add-ons-Manager unter „Themes“ installieren und aktivieren. Alte „Stream“-Themes vorher entfernen.
